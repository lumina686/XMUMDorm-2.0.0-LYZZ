# T2 报名与点赞接入同一套失败反馈

## 1. Where this task sits

- **Phase 1 失败看得见**，目标：未登录用户点关注被引导去登录，网络失败时看到原因。
- 本任务把 **R-1 社团失败态可见反馈** 扩到报名与点赞两个交互，并抽出三处共用的状态→提示映射。
- **Starts after**: T1 未登录关注登录引导。**Waits on it**: T4 失败态断言补全。

## 2. What the developer needs to know

**Read first**

- `app/src/features/clubs/ClubScreens.tsx:391-394,430-431` — 报名按钮只读 working，点赞只读 liked/count，state 都被丢弃。
- `app/src/features/clubs/useClubActivityRegistration.ts:14-19` — 报名态枚举（含 login/denied/failed）。
- `app/src/features/clubs/useClubLike.ts:8` — 点赞态枚举与关注一致。
- `app/src/__tests__/p3a5-club-details.test.tsx` — 详情屏幕测试，like/registration 已被 mock 出 state，直接换 state 值即可断言 UI。

**Settled**

- 反馈口径与 T1 相同：InlineNotice，login 态带登录动作，其余 danger；三处共用一个「状态→提示」映射（小函数或局部组件），Phase 6 收敛 hook 时它不改。
- hook 不改；详情页的导出失败提示维持现状，不并入。

**Edges and seam**

- 只改社团详情屏幕（活动+帖子两屏）；不动 hook 与后端。
- 缝：既有 `p3a5-club-details` 屏幕测试，零新增缝。

**Run**

- `cd app && npm test -- src/__tests__/p3a5-club-details.test.tsx src/__tests__/p3a5-club-discovery.test.tsx`
- `cd app && npx tsc --noEmit`，然后 `npm run lint`。

**Unknowns**

- 帖子详情无报名动作，映射需允许部分传入；若发现两屏渲染结构差异大到无法共用，停下来问，别复制两份。

## 3. The workflow

1. 读上述文件，一句话复述任务。
2. details 套件加用例 1（红）：registration.state='login' 断言登录引导。
3. 确认红，提交红测试；实现映射 + 活动详情接线，跑绿后提交。
4. 加用例 2（红）：like.state='denied' 断言 danger 提示；实现帖子/活动点赞接线，提交。
5. 两套件 + lint 全绿，提交收尾（如有残留）。
