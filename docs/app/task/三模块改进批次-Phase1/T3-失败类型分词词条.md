# T3 按失败类型拆分双语词条

## 1. Where this task sits

- **Phase 1 失败看得见**，目标：未登录用户点关注被引导去登录，网络失败时看到原因。
- 本任务把 **R-6 社团错误文案具体化**：失败提示与管理页错误按类型拆词条，替换笼统的「操作未完成，请重试」。
- **Starts after**: T2 报名点赞失败反馈（共用渲染位）。**Waits on it**: T5 全量回归。

## 2. What the developer needs to know

**Read first**

- `app/src/i18n/zh.ts` 与 `en.ts` 的 clubs 词条区 — 现有 clubs.actionFailed（zh.ts:637）是本任务要替换的笼统文案。
- `app/src/features/clubs/ClubScreens.tsx:261-268,286` — 管理页 mutate 只存 boolean，所有失败共用一句。
- `app/src/features/auth/authFailure.ts` — 已有的失败分型（会话失效/处罚/其他），管理页分型复用它。
- `app/src/__tests__/p2d-01-i18n-gate.test.ts` — 双语门禁，新键必须 zh/en 同步。

**Settled**

- 词条分型至少三类：需要登录、无权限/受限、网络或服务失败；每条满足宪法 10.4（错在哪 + 怎么改）。
- T1/T2 已用的临时通用键收敛进本任务的分型键；登录动作按钮文案沿用既有 `action.login`。
- 管理页错误从 boolean 升级为分型值，仍由服务端回执裁决，不猜原因。

**Edges and seam**

- 只改双语词典与社团屏幕的错误渲染；不动树洞/食堂词条。
- 缝：既有 i18n 门禁测试 + 管理屏幕测试（p3a5-club-management），零新增缝。

**Run**

- `cd app && npm test -- src/__tests__/p2d-01-i18n-gate.test.ts src/__tests__/p3a5-club-management.test.tsx`
- `cd app && npx tsc --noEmit`，然后 `npm run lint`。

**Unknowns**

- 若管理页某操作的失败类型服务端不可分辨，用通用失败词条兜底，并在提交说明里注明哪个操作仍通用。

## 3. The workflow

1. 读上述文件，一句话复述任务。
2. management 套件加用例（红）：删除操作失败（非鉴权错误）时显示网络/服务词条而非「操作未完成，请重试」。
3. 确认红，提交红测试。
4. 新增分型词条 zh/en 双侧，替换 T1/T2 临时键与 actionFailed 引用，跑绿提交。
5. i18n 门禁 + 相关屏幕套件回归，提交（如仍有残留）。
