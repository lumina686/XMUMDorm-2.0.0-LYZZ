# T4 发现页接搜索与分类筛选

## 1. Where this task sits

- **Phase 3 社团管理对齐 Web**，目标：社团管理员在 App 上完成邀请成员、设置角色，任何用户都能搜到目标社团。
- 本任务把 **R-4 社团发现页搜索与分类筛选** 接上：关键词 + 分类可组合，参数透传现成接口。
- **Starts after**: T3 无权限双向验证。**Waits on it**: T5 筛选与翻页回归。

## 2. What the developer needs to know

**Read first**

- `app/src/features/clubs/ClubScreens.tsx` 的 `ClubDiscoveryScreen` — 现在只传 `{page,pageSize}`；加载链已有 append 去重。
- `shared/api/clubs.js:33-37` 与 `routes/clubs.js` 列表端点 — `q`/`category` 参数现成。
- `app/src/features/clubs/model.ts:1` — `CLUB_CATEGORIES`（music/tech/culture/sport/art）与 `ClubCategory` 类型。
- `app/src/components/ui/SearchField.tsx` — 提交语义的搜索框（onChangeText/onSubmit/清除）。

**Settled**

- 搜索走**提交语义**（回车/确认触发），不做逐键请求——与食堂检索同款，比防抖更严；分类用 FilterChips（角色 button+selected，不是 tab）。
- 筛选变化即 refresh 回第 1 页；关键词与分类可组合；「全部」= 不传 category。
- 分类标签 zh/en 新增词条，UI 不猜服务端没有的类目。

**Edges and seam**

- 只改发现屏幕 + 双语词典 + 发现测试；不动 model 与后端。
- 缝：既有 `p3a5-club-discovery` 屏幕测试，零新增缝。

**Run**

- `cd app && npm test -- src/__tests__/p3a5-club-discovery.test.tsx src/__tests__/p2d-01-i18n-gate.test.ts`
- `cd app && npx tsc --noEmit`

**Unknowns**

- FilterChips 的选择回调签名以组件为准（单选语义由调用方维护）。

## 3. The workflow

1. 读上述文件，一句话复述任务。
2. 红用例：输入关键词提交 → `listClubs` 带 `q`；点分类片 → 带 `category`；组合两者同时带。
3. 跑红、提交红测试。
4. 实现 SearchField + FilterChips + 参数透传与词条。
5. 套件 + 门禁全绿提交。
