# T5 筛选与翻页互不覆盖回归

## 1. Where this task sits

- **Phase 3 社团管理对齐 Web**，目标：社团管理员在 App 上完成邀请成员、设置角色，任何用户都能搜到目标社团。
- 本任务是 **R-4 社团发现页搜索与分类筛选** 的状态证明，也是 **Phase 3 整体** 的批次回归。
- **Starts after**: T4 发现页搜索筛选。**Waits on it**: 无（Phase 3 收口）。

## 2. What the developer needs to know

**Read first**

- `app/src/features/square/CanteenSearchScreen.tsx:29-58` — 竞争丢弃的参照写法（generation/epoch + 忙锁）。
- `app/src/__tests__/p3a5-club-discovery.test.tsx` — 本任务主缝。
- 改进计划 Phase 3 的 Proof 行 — 批次通过标准。

**Settled**

- 筛选变化必须重置翻页（回第 1 页、清旧行）；append 沿用当前筛选；迟到的旧响应不得覆盖新筛选结果。
- 回归范围 = 社团全部套件 + i18n 门禁 + tsc + lint；预期除测试外零产品变更。

**Edges and seam**

- 产品代码只在 T4 实现有缺口时才动（红先）。

**Run**

- `cd app && npm test -- src/__tests__/p3-bing-club-follow.test.tsx src/__tests__/p3-bing-club-like.test.tsx src/__tests__/p3-bing-club-registration.test.tsx src/__tests__/p3-bing-clubs-model.test.ts src/__tests__/p3a5-club-details.test.tsx src/__tests__/p3a5-club-management.test.tsx src/__tests__/p3a5-club-discovery.test.tsx src/__tests__/p3a5-club-notifications.test.ts src/__tests__/p3a3-club-activity-publish.test.ts src/__tests__/p3a3-club-post-publish.test.ts src/__tests__/p2d-01-i18n-gate.test.ts`
- 根目录：`npm test -- __tests__/routes/clubs.test.js`
- `cd app && npx tsc --noEmit`，然后 `npm run lint`

**Unknowns**

- 若「迟到旧响应」在现有实现里无守卫，补最小 generation 守卫（红先），不扩大重构。

## 3. The workflow

1. 红用例：筛选切换后 append 不带旧筛选；迟到的未过滤响应不覆盖已过滤列表。
2. 有缺口则最小实现，跑绿。
3. 跑 Run 全量命令记录结果。
4. 全绿提交（含本任务新增测试）。
