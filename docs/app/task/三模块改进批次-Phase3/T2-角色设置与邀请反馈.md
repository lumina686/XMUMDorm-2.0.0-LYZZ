# T2 角色设置与邀请反馈

## 1. Where this task sits

- **Phase 3 社团管理对齐 Web**，目标：社团管理员在 App 上完成邀请成员、设置角色，任何用户都能搜到目标社团。
- 本任务把 **R-2 社团管理邀请与角色设置** 补完：邀请时选角色、成员角色可见、邮箱不存在的具体反馈。
- **Starts after**: T1 邀请成员端到端。**Waits on it**: T3 无权限双向验证。

## 2. What the developer needs to know

**Read first**

- `routes/clubs.js:800` — 邀请是 **upsert**（`ON DUPLICATE KEY UPDATE role`）：重复邀请即改角色，服务端**没有**冲突错误分支，改角色后的结果由资料重载呈现。
- `app/src/components/ui/SegmentedControl.tsx` — 2-5 项互斥选择的规范组件（成员/管理员用它，⛔ 不藏进 Select）。
- `app/src/features/clubs/ClubScreens.tsx` 管理页成员行 — 现在只显示昵称，角色标签缺失。
- `app/src/__tests__/p3a5-club-management.test.tsx` — 本任务缝。

**Settled**

- 角色只有 成员/管理员 两档，随邀请一次提交；不另做「改角色」入口（upsert 语义即角色设置）。
- 计划里「目标已是管理员时的冲突提示」按服务端事实收敛：无冲突分支可提示，重载后角色变化可见即反馈；不造客户端预判。
- 邮箱不存在（404）用邀请专属词条，其余失败沿用分型 InlineNotice。

**Edges and seam**

- 只改管理屏幕 + 双语词典；缝同 T1。

**Run**

- `cd app && npm test -- src/__tests__/p3a5-club-management.test.tsx src/__tests__/p2d-01-i18n-gate.test.ts`
- `cd app && npx tsc --noEmit`，然后 `npm run lint`

**Unknowns**

- SegmentedControl 的受控 props 以组件签名为准；若其选项类型不收 label，用词条现场映射。

## 3. The workflow

1. 读上述文件，一句话复述任务。
2. 红用例 1：默认角色「成员」，切到「管理员」后邀请 → `addClubMember(7, email, 'admin')`。
3. 红用例 2：404 未找到该用户 → 显示邀请专属提示（含邮箱核对指引）。
4. 跑红、提交红测试。
5. 实现 SegmentedControl 接线、成员行角色标签、404 分型；全绿提交。
