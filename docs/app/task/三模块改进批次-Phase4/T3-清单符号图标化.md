# T3 清单模板符号图标化

## 1. Where this task sits

- **Phase 4 万能墙能力收口**，目标：作者能删自己的墙帖，模板不再用文字符号模拟控件。
- 本任务把 **R-11 万能墙清单模板符号图标化**：`□` 文字符号换成两层图标体系内的 Lucide 图标。
- **Starts after**: T2 评论删除。**Waits on it**: T4 回归收口。

## 2. What the developer needs to know

**Read first**

- `app/src/features/campus/wallTemplates.tsx:28-35` — checklist 行以 `` `□ ${line}` `` 文字符号渲染；note 模板的 `•` 是排版圆点，保留。
- `app/src/components/ui/Icon.tsx` — 统一图标封装（size/tint），品牌位用 Lucide 子路径导入。
- `app/src/components/ui/InlineNotice.tsx:20-23` — Lucide 图标子路径导入的现成写法。

**Settled**

- 图标归属两层规则的**品牌位**（模板装饰），选 Lucide 方框类图标；系统控件位不适用本处。
- 排版圆点 `•` 保留；只动 checklist 一处。
- 每行图标与文本同行对齐（flex row、居中基线），不改变模板断行行为。

**Edges and seam**

- 只改墙模板组件与既有模板测试；缝：既有墙/校园组件测试。

**Run**

- `cd app && npm test -- src/__tests__/p2x-bing-wall-publish.test.ts src/__tests__/p2x-bing-campus.test.tsx`
- `cd app && npx tsc --noEmit`，然后 `npm run lint`

**Unknowns**

- Icon 组件若不支持文本行内对齐所需尺寸，以组件实际 API 为准调整（不新造图标组件）。

## 3. The workflow

1. 读上述文件，一句话复述任务。
2. 红用例：checklist 渲染结果中不再出现 `□` 字符，且出现图标元素。
3. 跑红、提交红测试。
4. 实现图标化与行对齐；全绿提交。
