# T1 删除自己的墙帖端到端（Phase 4 示踪弹道）

## 1. Where this task sits

- **Phase 4 万能墙能力收口**，目标：作者能删自己的墙帖，模板不再用文字符号模拟控件。
- 本任务把 **R-3 万能墙删除自己的墙帖与评论** 的主线打通：墙详情页作者可见删除入口，确认后删除并回到列表。
- **Starts after**: 无。**Waits on it**: T2 评论删除接线。

## 2. What the developer needs to know

**Read first**

- `routes/confessions.js:429-464` — 删除契约：仅作者或站管（403 其他）；帖子响应带 `viewer_is_author: 0|1`（window 与详情两处）。
- `app/src/features/campus/campusModel.ts:58-68` — `asWall` 目前把 `viewer_is_author` 剥掉了，要透传。
- `app/src/features/campus/CampusScreens.tsx` 详情屏 — 删除入口挂在帖子动作区；确认用 `AlertDialog`（社团删成员同款）。
- `app/src/__tests__/p2x-bing-campus.test.tsx` — 详情屏幕测试缝（`getConfession` 已 mock）。

**Settled**

- 匿名不变量不破：只透传布尔归属，不引入任何身份字段。
- 删除成功 → 乐观移除列表快照中的该行并返回列表；失败 → 分型提示（权限/网络），停留本页。
- 未登录不渲染删除入口（viewer_is_author 未登录恒 0）。

**Edges and seam**

- 只改校园特性（模型 + 详情屏）、双语词典、既有屏幕测试；不动后端。
- 缝：既有 `p2x-bing-campus` 屏幕测试，零新增缝。

**Run**

- `cd app && npm test -- src/__tests__/p2x-bing-campus.test.tsx src/__tests__/p2d-01-i18n-gate.test.ts`
- `cd app && npx tsc --noEmit`

**Unknowns**

- WallFeed 的快照键为 `[...QK.confessionWindow('_guest'), 'wallReadSnapshot']`；若移除快照后返回列表不自动刷新，改用显式过滤该行并触发 refresh。

## 3. The workflow

1. 读上述四处，一句话复述任务。
2. 红用例：作者帖显示删除入口、非作者与游客不显示；确认后调 `deleteConfession` 并返回。
3. 跑红、提交红测试。
4. 实现模型透传 + 删除入口 + 确认对话框 + 快照过滤；词条 zh/en。
5. 套件 + 门禁全绿提交。
