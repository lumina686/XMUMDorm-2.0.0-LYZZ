# T4 路由与点评全量回归

## 1. Where this task sits

- **Phase 5 后端与共享层收拢**，目标：可选鉴权三条路由一份实现、点评无编造评分。
- 本任务是 **Phase 5 整体** 的批次证明：三路由测试 + App 点评/食堂套件 + tsc + lint 一次跑绿。
- **Starts after**: T3 移除点评缺省评分。**Waits on it**: 无（Phase 5 收口）。

## 2. What the developer needs to know

**Read first**

- `__tests__/routes/` 三路由测试与 canteen 专项 — 后端回归面。
- `app/src/__tests__/` 的 p2y 点评/食堂系列 — App 侧回归面。
- 改进计划 Phase 5 的 Proof 行 — 批次通过标准。

**Settled**

- 预期零产品代码变更；失败只修可归因于本批的，红测试与修复分两笔提交。
- Web 端无自动化测试，回归以代码审读记录（T3 已含）。

**Edges and seam**

- 不改产品代码。

**Run**

- 根目录：`npm test -- __tests__/routes/posts.test.js __tests__/routes/clubs.test.js __tests__/routes/canteenPermissions.test.js __tests__/routes/canteenWriteGuards.test.js __tests__/shared/`
- `cd app && npm test -- src/__tests__/p2y-b03-review-form.test.tsx src/__tests__/p2y-a03-review-contract.test.tsx src/__tests__/p2y-b04-canteen-search.test.tsx src/__tests__/p2y-c01-canteen-cache.test.tsx src/__tests__/p3y5-dish-presentation.test.tsx src/__tests__/p2y-d03-dish-actions.test.tsx`
- `cd app && npx tsc --noEmit`（既有 `/agent` 环境项除外），然后 `npm run lint`

**Unknowns**

- `__tests__/shared/` 若含与本次无关的慢测试，仍全量跑（本批动了 shared/api）。
