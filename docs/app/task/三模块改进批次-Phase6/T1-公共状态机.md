# T1 抽公共交互状态机（Phase 6 示踪弹道）

## 1. Where this task sits

- **Phase 6 社团代码健康硬化**，目标：三个交互 hook 共享一台状态机，社团页按钮文案不再超长。
- 本任务把 **R-9 社团交互状态机收敛一处** 的主体抽完：关注/点赞/报名三个 hook 薄壳化，**既有测试断言一字不改跑通**。
- **Starts after**: 无。**Waits on it**: T2 按钮 label 收敛（互不依赖，可并行）。

## 2. What the developer needs to know

**Read first**

- `app/src/features/clubs/useClubFollow.ts`、`useClubLike.ts`、`useClubActivityRegistration.ts` — 三份同构：epoch/locked、六态、session 门、失败分型、双重 epoch 守卫。
- 差异清单 — 目标校验（clubId / targetType+targetId / activityId）、回执校验器、成功态（success / success / registered|cancelled）、reset 依赖。
- `app/src/__tests__/p3-bing-club-{follow,like,registration}.test.tsx` — 缝：断言不改跑通即等价证明。

**Settled**

- 公共 hook 收敛 epoch/locked/六态/session 门/失败分型；回执校验与目标校验作参数注入。
- 成功态由「应用回执」步骤返回（registration 按回执区分 registered/cancelled）。
- reset 由调用方在自己的 effect 里触发（三 hook 的 reset 依赖各不相同，这是真实差异）。
- 本任务零行为变化：任何断言红都意味着抽取不等价，回去修抽取而不是改断言。

**Edges and seam**

- 只改三个 hook 与新公共文件；缝：三套 hook 测试（断言不动）。

**Run**

- `cd app && npm test -- src/__tests__/p3-bing-club-follow.test.tsx src/__tests__/p3-bing-club-like.test.tsx src/__tests__/p3-bing-club-registration.test.tsx`
- `cd app && npx tsc --noEmit`

**Unknowns**

- 若 registration 的双动作（register/cancel）难以塞进单动作签名，允许公共层接受 `request` 闭包参数——但 epoch/锁语义必须仍只在公共层。

## 3. The workflow

1. 读三个 hook，列出同构/差异清单，一句话复述任务。
2. 写公共状态机文件（先不接线），跑三套测试确认无回归。
3. follow 接线 → 三套测试绿；like 接线 → 绿；registration 接线 → 绿（每步可独立提交）。
4. grep 门：三 hook 内不再出现 `epoch`/`locked`/`classifyAuthFailure`。
5. 提交。
